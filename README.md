# Book Inventory App

A sleek, modern, dashboard-style Book Inventory web application built using pure HTML5 and semantic CSS3. This project is meticulously crafted to fulfill rigorous automated test specifications (such as freeCodeCamp labs) while departing from standard table styling to deliver a premium, high-end user experience.

## Features

- **Premium Dark Aesthetics:** Built with a modern color palette utilizing CSS variables, high-contrast typography, and smooth micro-interactions.
- **Pure CSS Rating System:** Utilizes advanced CSS structural pseudo-classes and attribute selectors to dynamically fill star/circle ratings based on assigned classes without a single line of JavaScript.
- **Visual Status Badges:** Contextual ambient gradient backgrounds and borders mapped automatically to book statuses (`Read`, `To Read`, `In Progress`).
- **Test Suite Compliant:** Engineered specifically to clear strict automated regex evaluation tests requiring explicit tag and attribute selector pairings.
